# Homebrew tap for Sozvon

```sh
brew install --cask able1991/sozvon/sozvon
```

[Sozvon](https://able1991.github.io/sozvon/) updates itself after that, so `brew upgrade` is not needed.

`brew uninstall --zap` removes the app, its caches, logs and preferences. Your calls in `~/Documents/Calls` and the data in `~/Library/Application Support/Sozvon` stay.
